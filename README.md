# Hanane Ouriaghli — portfolio

Static portfolio website built with HTML and CSS. The site and its image assets are kept in the repository root so GitHub Pages can serve them directly.

## Publish with GitHub Pages

1. Push the contents of this folder to the `main` branch of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then save.
5. After deployment completes, open the URL shown in the Pages settings.

The entry page is `index.html`. Keep `style.css` and all four image files in the repository root; the page references them using relative paths.
